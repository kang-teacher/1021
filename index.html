방법 ①

구글 스프레드시트 + Apps Script로 웹페이지 만들기

구글 시트에 있는 데이터(명단, 설문 결과, 도서 목록 등)를 그대로 읽어 보여주는 웹페이지를 만듭니다. 시트만 고치면 웹페이지도 바로 바뀌기 때문에, 선생님이 관리하기 가장 쉬운 학급 웹앱이 됩니다.

이런 데 써요

  • 구글 폼 응답을 모아 보여주는 게시판
  • 학생별 과제 제출 현황판
  • 학급 도서·물품 대여 목록
  • 이름을 입력하면 내 자리·모둠을 알려주는 조회 페이지

구조 이해하기

구글 시트
데이터→ Code.gs
데이터 읽기→ index.html
화면 보여주기→ 웹 앱 배포
주소 생성

따라 하기

  1. 시트 준비: 새 구글 스프레드시트를 만들고, 첫 줄에 제목(예: 이름 | 모둠 | 역할), 둘째 줄부터 데이터를 입력합니다. 시트 이름은 시트1로 둡니다.
  2. Apps Script 열기: 메뉴 확장 프로그램 → Apps Script를 누릅니다.
  3. Code.gs 작성: 기본 코드를 지우고 아래 코드를 붙여넣습니다.
Code.gs
// 웹 주소로 접속하면 index.html을 보여줍니다
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('우리 반 모둠 안내')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

// 시트의 데이터를 화면(index.html)에 넘겨줍니다
function getData() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('시트1');
  return sheet.getDataRange().getDisplayValues();
}
  1. index.html 추가: 왼쪽 파일 + → HTML을 눌러 이름을 index로 만들고 아래 코드를 붙여넣습니다.
index.html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: sans-serif; padding: 16px; }
    table { border-collapse: collapse; width: 100%; }
    th, td { border: 1px solid #ccc; padding: 8px; }
    th { background: #f0f4ff; }
  </style>
</head>
<body>
  <h1>우리 반 모둠 안내</h1>
  <div id="list">불러오는 중...</div>

  <script>
    // Code.gs의 getData()를 불러와서 표로 그립니다
    google.script.run.withSuccessHandler(function (rows) {
      let html = '<table>';
      rows.forEach(function (row, i) {
        const tag = i === 0 ? 'th' : 'td';
        html += '<tr>' + row.map(c => '<' + tag + '>' + c + '</' + tag + '>').join('') + '</tr>';
      });
      document.getElementById('list').innerHTML = html + '</table>';
    }).getData();
  </script>
</body>
</html>
  1. 배포: 오른쪽 위 배포 → 새 배포 → 유형 톱니바퀴에서 웹 앱 선택.
    • 다음 사용자 인증 정보로 실행: 나
    • 액세스 권한: 모든 사용자(학생이 로그인 없이 보려면) 또는 우리 학교 도메인 사용자
  2. 권한 승인: 처음 한 번 "액세스 승인" → 내 구글 계정 선택 → 고급 → (안전하지 않은 페이지)로 이동 → 허용. 내가 만든 스크립트라서 나오는 경고이니 안심하세요.
  3. 주소 공유: 생성된 https://script.google.com/macros/s/…/exec 주소를 복사합니다. 너무 길면 외솔.한국으로 짧게 줄여 QR로 나눠 주세요.

2) 표 대신 모둠별 카드 모양으로 보여주고, 모바일에서 예쁘게.

⚠️ 코드를 고친 뒤에는 배포 → 배포 관리 → 연필 아이콘 → 버전 새 버전 → 배포를 해야 같은 주소에 반영됩니다.

🔒 학생 개인정보(연락처, 성적 등)가 담긴 시트는 "모든 사용자" 공개로 배포하지 마세요.

방법 ②

카페24로 나만의 도메인 사이트 만들기

카페24는 도메인(인터넷 주소) 구매와 호스팅(사이트를 올려 둘 공간)을 한곳에서 할 수 있는 서비스입니다. 원하는 이름의 주소를 갖고, AI가 만든 HTML을 그 주소에 올리면 진짜 "내 사이트"가 됩니다.

사례: 직접 만든 모바일 청첩장

Claude와 대화하며 만든 HTML 청첩장을 카페24에 올리고, .shop 도메인을 연결한 사례입니다. 이미지는 카페24에, 배경음악·영상 파일은 깃허브에 올려 함께 사용했습니다.

사례 사이트 보기 ↗

  • 💌 초대 글
  • 📞 연락처(전화·문자 버튼)
  • 🖼️ 사진 갤러리
  • ⏳ D-day 카운터
  • 🗺️ 오시는 길·길안내
  • 🚌 예식·셔틀 정보
  • 📝 방명록·참석 의사(RSVP)
  • 💳 마음 전하실 곳
  • 🎵 배경음악, 카카오톡 공유

만드는 흐름

  1. AI로 HTML 만들기: 필요한 섹션(위 목록 참고)을 정리해 "모바일 청첩장 HTML 한 파일로"를 요청하고, 미리보기를 보며 문구·색·배치를 대화로 고칩니다.
  2. 도메인 구매: 카페24에서 원하는 주소를 검색합니다. .shop, .site 등은 첫 해가 저렴한 편이고, 한글 주소(예: 우리반.shop)도 가능합니다.
  3. 호스팅(올릴 공간) 준비: 카페24의 웹호스팅 또는 쇼핑몰 서비스를 개설합니다. 쇼핑몰은 무료로 열 수 있어 간단한 사이트를 올리는 데 활용하기도 합니다.
  4. HTML 올리기: 웹호스팅이라면 FTP(파일질라 등) 또는 웹FTP로 index.html을 올리고, 쇼핑몰이라면 디자인 관리의 HTML 편집 화면에 코드를 붙여넣습니다.
  5. 이미지·파일 올리기: 사진은 카페24 파일 업로더에 올리고, 코드의 이미지 주소를 업로드된 주소로 바꿉니다. (AI에게 "이 주소들로 바꿔줘"라고 하면 편합니다.)
  6. 도메인 연결: 구매한 도메인을 호스팅(쇼핑몰)에 연결하고, 몇 시간 뒤 주소로 접속해 확인합니다.
  7. 공유 미리보기 설정: 카카오톡 공유 시 보일 제목·이미지(og:title, og:image)를 AI에게 넣어 달라고 합니다.

수업·학교에서 활용한다면

  • 학교 축제·동아리 발표회 초대장, 졸업 기념 사이트
  • 학생 프로젝트 결과물을 "진짜 주소"로 발표하는 경험

⚠️ 도메인·호스팅은 유료이며 매년 연장 비용이 듭니다. 연락처·계좌 등 개인정보는 공개 사이트에 올릴 때 신중하게 판단하세요.

방법 ③

깃허브 + Claude로 수업 자료 사이트 만들기

깃허브(GitHub)는 파일을 버전별로 보관하는 온라인 저장소이고, GitHub Pages를 켜면 저장소의 HTML이 무료 웹사이트가 됩니다. 여기에 Claude를 연동하면 "3차시 실습 페이지 추가해줘"처럼 말로 요청하는 것만으로 Claude가 파일을 만들고 저장소에 올려 줍니다. 지금 보고 계신 이 연수 페이지도 이 방법으로 만들었습니다.

왜 깃허브인가요?

  • 무료 웹사이트 주소(아이디.github.io/저장소)
  • 차시가 늘어나도 한 사이트에 계속 쌓을 수 있음
  • 모든 수정 기록이 남아 언제든 되돌리기 가능
  • 다른 선생님이 복사(포크)해서 재사용하기 쉬움

Claude 연동으로 달라지는 점

  • 코드를 복사·붙여넣기 하지 않아도 됨
  • Claude가 저장소 전체를 읽고 일관된 디자인으로 추가
  • 변경 내용을 PR(변경 요청)로 올려 확인 후 반영
  • 사진 속 물체를 찾는 YOLO 같은 AI 실습 자료도 단계별 페이지로 정리

처음 한 번: 준비하기

  1. 깃허브 가입: github.com에서 계정을 만듭니다. 아이디가 사이트 주소에 들어가니 짧게 정하세요.
  2. 저장소 만들기: 오른쪽 위 + → New repository → 이름(예: ai-class) 입력, Public, Add a README file 체크 → Create repository.
  3. Claude와 연결: claude.ai/code에 접속해 깃허브 계정을 연결하고, 방금 만든 저장소를 선택합니다. (Claude 앱의 프로젝트에 저장소를 연결해도 됩니다.)
  4. GitHub Pages 켜기: 저장소 Settings → Pages → Source: Deploy from a branch, Branch: main / (root) → Save. 잠시 후 https://아이디.github.io/ai-class/ 주소가 생깁니다.

방법 ④ · 짧게

외솔.한국으로 HTML 파일 한 장 바로 올리기

외솔.한국은 울산교육청과 함께 운영하는 무료 서비스로, 긴 주소를 짧은 한글 주소로 바꿔 주고(QR 코드 지원), 외솔 드롭으로 HTML 파일을 바로 웹페이지로 배포할 수 있습니다.

외솔 드롭: HTML 배포

  1. AI가 만든 HTML 파일을 점선 영역에 끌어다 놓기
    (또는 코드 붙여넣기, 최대 1MB)
  2. 배포 주소 정하기 → 외솔.한국/우리반안내
  3. 로그인 후 배포하기
  4. 대시보드에서 수정·내리기 가능
    (유지 기간 1년, 베타 기능)

URL 줄이기

  1. 원본 주소 입력
    (예: Apps Script 웹앱 주소)
  2. 원하는 한글 단축 주소 정하기
  3. URL 줄이기 → QR 코드로 학생에게 공유

로그인하지 않고 만든 단축 주소는 1주일만 유지됩니다.
